# 🎓 Mistral Education

**AI Academic Assistant for Students** — Powered by Mistral AI

## About

Mistral Education is an AI-powered educational platform that helps students organize their studies, understand their lessons, and improve their academic results.

## Features (MVP)

- 🤖 **Homework Help AI** — Interactive chat with Mistral AI for homework assistance
- 📊 **Weakness Detection** — Analyze grades and identify areas for improvement
- 🏋️ **Personalized Exercises** — Adaptive exercises based on detected weaknesses
- 📅 **Study Planner** — Smart revision planning with deadlines management

## Tech Stack

- React 18 + TypeScript + Vite
- Tailwind CSS + Framer Motion
- Zustand + Recharts
- Mistral AI API
